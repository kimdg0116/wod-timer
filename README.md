# WOD 타이머

크로스핏 WOD와 추가 운동에 쓰는 인터벌 타이머. 폰 홈 화면에 설치해서 쓴다 (PWA, 오프라인 동작).

https://kimdg0116.github.io/wod-timer/

- 타바타: 준비, 운동, 휴식, 라운드, 사이클, 사이클 사이 휴식, 쿨 다운
- 라운드: 준비, 운동, 휴식, 라운드, 쿨 다운 (EMOM, AMRAP)
- 스톱워치: 준비 뒤 시간을 재고, 정한 랩마다 소리로 알림 (For Time)
- 가로로 돌리면 숫자를 크게 보여 줘서 여럿이 같이 보기 좋다
- 소리 6종, 1초 똑딱 소리, 한국어 음성 안내, 운동 중 화면 켜 두기
- 자주 쓰는 설정은 "내 타이머"에 저장

확인: `node test_plan.mjs`
